Dit los je op de server op (in de container van de app):

  • python -m app.auth reset-password kiest een nieuw wachtwoord; elke browser wordt uitgelogd.
  • python -m app.auth reset-mfa wist de authenticator en de herstelcodes en geeft een eenmalige code om een nieuwe te koppelen.
  • python -m app.auth clear-throttle heft een blokkade na te veel foute pogingen op.
