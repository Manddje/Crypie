Zo gebruik je het

Claude Code, Claude Desktop, en wat je kunt vragen
  1. Genereer een token (hieronder) en bewaar het meteen: het wordt één keer getoond. Kwijt of gelekt? Genereer een nieuw token; het oude werkt dan niet meer.
  2. Claude Code (op je eigen computer): voer dit uit in een terminal. 
    claude mcp add --transport http crypie {{ mcp_url }} --header "Authorization: Bearer {{ shown }}"
    Controleer met claude mcp list; daarna zie je in een gesprek de tools van crypie.
  3. Claude Desktop: de app kent voor een eigen server met een token geen instelling (Custom connectors verwacht OAuth). Gebruik de brug mcp-remote (vraagt Node.js). Open claude_desktop_config.json (macOS: ~/Library/Application Support/Claude/, Windows: %APPDATA%\Claude\) en voeg toe: 
    {
  "mcpServers": {
    "crypie": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "{{ mcp_url }}", "--header", "Authorization:${CRYPIE_AUTH}"],
      "env": { "CRYPIE_AUTH": "Bearer {{ shown }}" }
    }
  }
}
    Herstart Claude Desktop; onder het gereedschap-icoon staat dan crypie.
  4. Vraag Claude wat je wilt weten: "Hoe staat de bot ervoor?", "Waarom kocht hij gisteren niet?", "Hoe doen de open posities het?", "Wat zegt het nieuws over ETH?", "Vergelijk het evaluatievoorstel met de huidige strategie". Claude leest dezelfde gegevens als dit portaal: status, posities, beslissingen, orders, journaal, nieuws, evaluaties, strategie, plan, instellingen en Claude-kosten.
  5. Ingrijpen kan ook, maar alleen als jij erom vraagt: noodstop, Claude een markt laten beoordelen, een cyclus of evaluatie draaien, een order, de strategie, het plan, notities en instellingen. Gevoelige instellingen en live orders vragen je wachtwoord; Claude vraagt daar nooit zelf om. Geef het in het gesprek alleen als je die wijziging echt wilt.

Het token opent alleen de API en /mcp, nooit een pagina; in een browser is het nutteloos. Wil je het intrekken, dan staat dat hieronder.
