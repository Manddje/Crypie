Alleen met de setup-link van de server

Een account aanmaken kan alleen met de geheime setup-link. De server zet die bij het starten in de logs: zoek naar /setup?token= en open die link. Heb je zelf SETUP_TOKEN ingesteld, gebruik dan /setup?token= met die waarde.

Of maak het account op de server aan met python -m app.auth create-account.
