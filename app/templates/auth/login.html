Je niet-opgeslagen wijzigingen in Instellingen staan nog in deze browser. Na het inloggen kun je ze in het blok terugzetten.

Daarna vul je een code uit je authenticator-app in. Je blijft {{ settings.auth_session_hours }} uur ingelogd.

Wachtwoord of authenticator kwijt?

Dit los je op de server op (in de container van de app):

  • python -m app.auth reset-password kiest een nieuw wachtwoord; elke browser wordt uitgelogd.
  • python -m app.auth reset-mfa wist de authenticator en de herstelcodes en geeft een eenmalige code om een nieuwe te koppelen.
  • python -m app.auth clear-throttle heft een blokkade na te veel foute pogingen op.

Telefoon kwijt maar nog herstelcodes? Log gewoon in en kies bij de code 'Herstelcode gebruiken'.

Eerste keer?

Het account maak je aan via de setup-link die de server bij het starten in de logs zet (zoek naar /setup?token=), of op de server met python -m app.auth create-account.
